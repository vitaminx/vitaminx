# 维护规则与变更记录

基线：2026-10-26 上一版加密货币规则压缩包；本次在其去重数据上继续整理。
新加密货币站点依据 CoinGecko、DeFiLlama、DappRadar、RootData、L2BEAT、Blockscout、
ChainList 等研究资料和部分官网核对后**有限选择**加入，不是爬取所有项目。

## 数量变化

- 原加密货币默认版 334 条；新版 417 条。
- 原加密货币扩展版 397 条；新版 483 条。
- 新增独立加密货币资料子集 51 条。
- 香港券商默认版 144 条；扩展版 148 条。
- 香港银行默认版 37 条；扩展版 44 条。

## 变更原则

1. 重复域名仅保留一个；被 `DOMAIN-SUFFIX` 覆盖的完全同域/子域名规则删去。
2. 完全匹配 `DOMAIN` 只用于不应扩展匹配的第三方父域名或特殊 API Host。
3. 排除不专属于金融服务提供商的共享 CDN/SDK/云服务地址。
4. `crypto-directory` 与 `crypto-default` 允许**有意包含关系**；其它主类尽量避免重叠。
5. 只修改 `data/*.json` 不会自动重建其它规则；需要通过转换脚本或人工重新导出
   并重新执行校验。
6. 本 ZIP 不包含自动拉取/更新脚本；运行时没有联网。
7. 部分平台已停运或可能更换域名。扩展版不保证历史站点所有权、官方状态、安全性。

## 安全重点

本规则集纯粹用于网络访问策略匹配，**绝不能用来判定哪些交易网址是官方、安全、
受监管或值得投资的。** 对金融域名请从官方 App、交易所官方公告、
HKMA / SFC 登记册核验，避免直接访问来源清单里的疑似变体域名。
